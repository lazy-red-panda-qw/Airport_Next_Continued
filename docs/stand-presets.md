# 0.6.7 机坪基础布局与独立配套

制作日期：2026-10-02。基础模板先把机坪边界、飞机引导、安全分界、角部禁停和两侧服务空间搭好；廊桥活动区、轮位、设备停车框、停止点和编号分别放置。玩家先铺Surface、放一张基础布局，再加适合实际飞机和道具的组件，校准一个后成组复制。入口沿用 **Decal → 道路贴花 / RoadMarkings**。

本轮重绘原8个模板，保留目录、Prefab身份和UiPriority；增加开放回转、开放贯通两种机位及梯形／折角两种独立禁停模块。全包504项：461 Decal、34 NetLane、9 Surface。原500个Prefab身份保留，其余492项资产及既有翻译值未改，包括上一轮23项独立配套。作者字形与RGB177白色保持原样。

## 跨机场核对后的拆分依据

没有从已读ICAO／地区文件中得到一种全球统一的完整机位外框，也没有机场样本统计可证明某个外框“最普遍”。常见的功能核心是黄色航空器引导、按实际停靠配置设置的停止／对准／转弯参照，以及服务安全分界。ICAO Annex14 §5.2.13和CAAM §2.1按停车配置选择所需标记；CAA CAP637 §2.4也描述多种布局。完整地面设计不能从某一机场照片直接推广到所有机场。

### 八档折角基础布局

两处前角为三角禁停斜线，红线0.10m、45°图示角度、垂直透明净距0.75m；红色0.10m折角安全线保护完整参照机体矩形。白色0.15m外界和侧面分界将两侧留白分出来，尾端为单白线；黄色纵向引导线宽0.15m（两档通航）或0.30m（其他），各侧黑边0.075m。尾部留3m编号空档，引入线延长8m。

非通航两侧留白条带分别6／8m，通航为3／5m；这些是基础空间预设，不是已经画好车道、停车格或特定机场的通行区。头部空白可放廊桥轮位或其他服务组件，侧条带可按机场需求增设设备框。每个位都没有固定GSE停车位置，也没有固定廊桥铰点、轮组位置或运动方向。

机头朝贴图上方，飞机纵轴对齐黄线。名义鼻尖和轴线坐标见[几何清单](stand-presets.json)的`nose_reference_y_m`／`axis_x_m`；`aircraft_rect_m`保存完整机长／翼展。名义鼻尖距前界至少12m，鼻轮在其后；鼻轮停止横条必须按实际鼻轮摆放，不能拿鼻尖坐标当鼻轮。添加廊桥或设备后，应重新核查完整结构与实际飞机净空；基础区域留白并不自动保证任何道具都适配。

### 开放机位

7701是简洁开放回转引导，沒有围框、红色保护包络描边、设备停车框或服务通道。12m曲线半径为造景预设，出口直线8m及2×2m方向箭头；停止／转弯条仍独立。几何清单保留未涂漆的保守扫掠区域，半径√(L²+(S/2)²)加C覆盖所选连续曲线，区域可以超出贴花投影；放置玩家自己的障碍物时应留足这些空间。未测鼻轮距和转向角，不把该弧线称为任何机型通用最小转弯半径。

7711的停靠段笔直、两端开放，只有侧面安全／留白分界及引出箭头。整张投影38.80×44.90m，中央机位段28.2m，两端各8m引导延伸。外部滑行道接入弧线不烘焙到机位，玩家用现有黄色NetLane按自己的滑行道位置连接。它不是独立S形滑行线路模板。贯通方向不设头部横墙或固定廊桥工作区。

## 独立可选组件的使用

优先按实际用途挑组件：禁停斜线限制车辆设备停放，设备停车框明确可停车，轮位标记的是廊桥不用时的停放点，活动区要按实际桥的轨迹配置。可选择原Heathrow样式放射线，也可用禁停斜线模块或8500 Surface绘任意轮廓，配0.10m红色／白色NetLane描边；后者没有固定铰点或扇区。

7832梯形、7833折角只是两种方便摆放的红色禁停轮廓，线宽与净距复用CAAM §11。不是规定所有廊桥应画成这两个形状，也没有把轮位绑定到其中。颜色与边线在不同机场的语义不可随意互换；本包明确标注所选CAAM比例。

基础与组件都是透明Decal，底层道面用Surface铺；8500禁停Surface继续可以画任意多边形。已有组件足够覆盖大小和形状变化，本轮不增加依赖实际廊桥模型的Surface自动区域，也不改机场运行／存档逻辑。

预览见[基础与可选模块总览](stand-preview.png)、[基础贴图与玩家组合示意](apron-layout-example.png)。右图的飞机、314编号及额外组件位置仅是组合示意，不会写进基础资产。制作入口为`asset-specs.json`和`tools/asset_pipeline.py`，基础几何在`tools/apron_layouts.py`；不要重新bootstrap。离线检查与游戏验收范围见[第八轮指南](test-round-8.md)。
