# 服务车辆道路：独立组件与成套预设

0.7.1.0测试开发版增加14条NetLane，全部位于 **NetLane → 道路线条 / RoadMarking**。普通道路、穿越段和独立边线并存；Surface先铺道面，标线沿道路中心路径或各条边界拉取。所有白色保持作者实测RGB177/177/177，黑色沿用RGB0/0/0，绘制层42。本轮不更新发布配置、正式指南或PDF。

## 成套预设

| 编号 | 内容 | 标线外缘总宽 | 自带中心线 |
|---|---|---|---|
|7540|普通单车道|4 m|无|
|7541|普通双车道|7.5 m|白色15 cm虚线，实4.5 m、空7.5 m|
|7550 / 7551|CAAM穿越段，接单／双车道|4 / 7.5 m|中央留白|
|7560 / 7561|FAA白色拉链段，单／双车道|4 / 7.5 m|单车道无；双车道带分道虚线|
|7570 / 7571|FAA黑底棋盘段，单／双车道|白色外缘4 / 7.5 m|单车道无；双车道带分道虚线及黑色对比边|

这里的宽度指两侧白色标线**最外缘之间的总宽**，不含透明留白；不是每条车道的净宽。无黑底的投影宽为4.3 / 7.8 m；黑底版黑色外缘总宽为4.3 / 7.8 m，投影宽为4.6 / 8.1 m。普通单车道两侧内缘净距为3.70 m；普通双车道在中心白色实段旁的单侧净距为3.525 m。道路内部透明，不自带沥青或混凝土。

普通预设沿道路中心路径一次拉取。单车道是供单列车辆使用的宽度档位，不自动管理单向／双向交通。双车道可用于双向道路，方向箭头和车道用途由玩家另放。普通单车道使用9 m内部连续贴图，普通双车道为12 m分道周期。

穿越段在两侧一次画出交错白块；4 / 7.5 m档用于连接对应普通道路。CAAM每块长1 m、单列厚0.10 m、交错带总厚0.20 m、完整周期2 m；FAA每块长1.2 m、单列厚0.30 m、交错带总厚0.60 m、完整周期2.4 m。左右采用镜像、同相位的包内布置。固定白色外缘宽度下，交错块的内侧突出量与普通边线不同，端部与相位需要玩家对齐。

**中心线不能按“穿越段”一概去掉。** FAA §5.2.5.1及图A-25包括车道分隔虚线，拉链边线只是替代普通实边线。因此7561与7571保留0.15 m分道线，实4.5 / 空7.5 m；整套贴图周期12 m包含5次2.4 m拉链重复。CAAM图20-2在穿越区中央未绘分道线，7550/7551按此图留白，这不表示所有机场穿越区禁止中心线。需要不同运营方布置时用7510独立画，遇航空器标线留空。

**黑白棋盘与白色拉链的区别在于黑漆。** 7521/7560/7561白块之间为透明道面；7522/7570/7571把空隙填成真实黑色，并在白块带两侧各增加0.15 m黑边，总带宽0.90 m。黑底双车道的分道虚线也有0.15 m黑色对比边，白线间的道路区域仍透明。

## 独立组件

|编号|组件|尺寸|
|---|---|---|
|7500|白色普通边线 · FAA|连续0.15 m，两侧分别画|
|7510|白色分道虚线 · FAA|0.15 m，实4.5 m / 空7.5 m，周期12 m|
|7520|CAAM穿越交错边线|单块1 × 0.10 m，总带宽0.20 m，周期2 m|
|7521|FAA拉链式道路边线|单块1.2 × 0.30 m，总带宽0.60 m，周期2.4 m|
|7522|FAA黑底棋盘边线|同7521白块；总黑带宽0.90 m，含两侧各0.15 m黑边|
|7530|白色车辆停止横线 · FAA|厚0.60 m，横向拉过相应车道|

非预设宽度、局部扩宽、转角及复杂路口可以用7500两侧独立画边线，再以7510布置分道线。用独立组件调整间距，避免缩放成套资产：整体缩放会同时改变路宽、笔画、虚线长度和重复周期。文字、编号及箭头复用现有透明字符和箭头。

## 来源与适用条件

- [FAA AC150/5340-1M Change1](https://www.faa.gov/documentLibrary/media/Advisory_Circular/150-5340-1M-Chg-1-Airport-Markings.pdf) §5.2.3/5.2.5.1、图A-15/A-25：普通边线／分道虚线15 cm；虚线4.5 / 7.5 m；交错块1.2 × 0.30 m；车辆停止横条0.60 m。这组用于航空器活动区域内或穿越该区域的车辆道路；完全位于航空器活动区域之外的道路按当地道路规则选择，不宣称所有服务道路必须用FAA图样。
- 同份FAA文件§1.4、表1-2与附录C说明浅色道面的黑色对比增强：一般黑边至少0.15 m，多线或虚线图样内部空隙填黑。车辆标线属于黑边推荐范围，白色无黑底版与黑底版可以并存；本包选择0.15 m黑边，不把黑色改成发光效果。
- 图A-15将4 ft注为1.3 m，图A-25将2 ft注为0.67 m，分别与正文1.2 m及0.6 m不一致。本包采用正文米制值，不按图中像素测距。2025-06-24勘误未列这两处。
- [FAA AC150/5300-13B Change1（含2025-04-03勘误）](https://www.faa.gov/documentLibrary/media/Advisory_Circular/AC-150-5300-13B-Airport-Design-Chg1-w-errata.pdf) §5.19.3：较低繁忙度商业机场机坪单车道通常3.7–4.3 m，繁忙机场双向道路通常总宽6.1–7.6 m。4 m及7.5 m是这一指导范围内选定的包内档位，属于设计考虑，不是统一强制值。§6.5.5的导航设施检修道路宽度范围没有拿来替代机坪道路指导。
- [CAAM CAGM1403 Issue02 Rev00（2025-02-04）](https://www.caam.gov.my/wp-content/uploads/2025/02/CAGM-1403-Apron-Markings-and-Signs-ISS02_REV00.pdf) 第20章、图20-1/2：服务道路穿越滑行道或机位滑行通道的白色交错标线。A/B各1 m，C至少0.10 m；C是单列厚度。预设采用其最低笔画、FAA机坪指导范围内的包内道路宽度，**不是CAAM规定的4/7.5 m道路模板**。
- 樟宜2021驾驶手册§6.1区分白色道路分道、停止线等用途；悉尼2020驾驶手册印刷页34/35展示普通边线及滑行道穿越拉链图样。它们只作机场用途对照，未提供本批的统一尺寸来源。
- [YVR Airside Traffic Directives，April 2026](https://www.yvr.ca/-/media/yvr/documents/airside-vehicles/2026/2026-airside-traffic-directives---april.pdf) §7.6、页17/18展示有分道线的车辆道路和两列黑白棋盘边缘实拍，证明真实黑漆版本存在。该手册没有给出棋盘块统一尺寸；本包黑底版的白块及黑边尺寸来自FAA，不冒称照搬YVR全套工程尺寸。

用户提到的单列“一段黑、一段白”图样来源已确认是Sully资产包。当前没有核实其现实机场及工程尺寸；本轮不把另一个资产包的造景图样直接冠以FAA、CAAM或ICAO标准名称。这不构成“现实中一定不存在”的结论。普通实边线、白色交错边线和黑底棋盘分别按上述来源保留。

车辆道路标线与跑道／滑行道标线相交时，按FAA §5.2.3中断车辆标线，保留航空器标线。预设不自动识别交叉对象或裁切贴图；玩家需要分段拉取、留空，必要时用独立组件补齐。穿越段没有捆绑固定停止距离；7530按飞机净空、场地和当地规则独立摆放。车用道路不套用航空器四线等待线。
